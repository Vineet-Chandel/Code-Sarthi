## ❯ The Problem

Developers juggle **10+ disconnected tools** across their career journey:

```
Resume Builders   ATS Checkers   LinkedIn   GitHub   Discord   Slack
      Zoom             Trello        Notion      Interview Platforms ...
```

The result? Scattered workflows, duplicated effort, inconsistent resumes, and lost time. **CodeSarthi eliminates the fragmentation.**

---

## ❯ What is CodeSarthi?

CodeSarthi is an **AI-powered career acceleration and developer collaboration ecosystem** — a unified platform where developers can:

- ✦ Build AI-optimized resumes tailored to specific job descriptions
- ✦ Get real-time AI coaching through mock interviews
- ✦ Collaborate with teams through integrated messaging and voice/video
- ✦ Track projects with an AI project manager
- ✦ Grow their career with Shastra AI, a persistent intelligent career companion

> **Vision:** *Empowering every developer with AI to build, collaborate, and grow their career.*

### 📄 Resume Intelligence Engine — 9-Stage AI Pipeline

The flagship feature. Not just a resume builder — a full intelligence pipeline that analyzes, rewrites, and optimizes resumes like a senior recruiter.

```
┌─────────────┐    ┌─────────────────┐    ┌────────────────────────────┐
│  Stage 1    │    │   Stage 2       │    │        Stage 3–6           │
│             │    │                 │    │       (Parallel)            │
│  Profile    │──▶│  Targeting      │──▶│  Summary  │ Experience      │
│  Audit      │    │  Strategy       │    │  Rewrite  │ Rewrite         │
│             │    │                 │    │  Projects │ Skills Optim.   │
└─────────────┘    └─────────────────┘    └────────────────────────────┘
       │                   │                           │
       ▼                   ▼                           ▼
  Health Score       JD Blueprint              Recruiter-Ready
  Strengths          Keywords Map              Section Content
  Weaknesses         Positioning
  
┌─────────────┐    ┌─────────────────┐    ┌────────────────────────────┐
│  Stage 7    │    │   Stage 8       │    │        Stage 9             │
│             │    │                 │    │                             │
│  Resume     │──▶│  ATS Analysis   │──▶│  Skill Gap Analysis        │
│  Assembly   │    │                 │    │  + Roadmap                  │
└─────────────┘    └─────────────────┘    └────────────────────────────┘
                    ATS Score              Coverage %
                    Format Score           Missing Tech
                    Readability            Certifications
```

**Stage 1 — Profile Audit** evaluates ATS readiness, formatting, keyword density, action verb quality, and missing sections, producing a health score with prioritized improvements.

**Stage 2 — Targeting Strategy** reads the job description and creates a positioning blueprint: recruiter narrative, must-use keywords, tone instructions, and words to avoid.

**Stages 3–6** (run in parallel) rewrite Summary, Experience bullets, Projects, and Skills using the blueprint.

*Example transformation:*
```
Before  →  "Worked on React project."
After   →  "Developed scalable React applications serving 5,000+ users,
            improving rendering performance by 42%."
```

**Stage 7 — Assembly** merges all optimized sections into a unified resume.

**Stage 8 — ATS Analysis** returns a comprehensive score across keyword coverage, formatting, and recruiter-friendliness.

**Stage 9 — Skill Gap Analysis** compares candidate skills against job requirements and produces a prioritized learning roadmap with certification recommendations.

## ❯ Quick Start

### Frontend

```bash
# Clone the frontend
git clone https://github.com/codesarthi/codesarthi-front.git
cd codesarthi-front

# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

### Backend

```bash
# Clone the backend
git clone https://github.com/Vineet-Chandel/codesarthi-backend.git
cd codesarthi-backend
npm install

# Configure environment
cp .env.example .env
# Fill in: MONGO_URI, JWT_SECRET, GROQ_API_KEY, CLOUDINARY_*, REDIS_URL, RESEND_API_KEY

npm run dev    # development (nodemon)
npm start      # production
```
